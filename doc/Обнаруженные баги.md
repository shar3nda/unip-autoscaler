* Неверное выражение `avg`

После масштабирования вверх до 2 экземпляров API Prometheus возвращает два значения по ключу `result`:

```
> curl -s "http://$PROMETHEUS_URL:9090/api/v1/query" --data-urlencode query='avg by (pod) (avg_over_time(container_memory_working_set_bytes{pod=~"module-resourse-test-mlcmp-deployment-.*",container!=""}[300s:])) / 1024 / 1024' | jq .
{
  "status": "success",
  "data": {
    "resultType": "vector",
    "result": [
      {
        "metric": {
          "pod": "module-resourse-test-mlcmp-deployment-75f9cdc889-wfpt6"
        },
        "value": [
          1740983983.094,
          "1143.65625"
        ]
      },
      {
        "metric": {
          "pod": "module-resourse-test-mlcmp-deployment-75f9cdc889-vwmkm"
        },
        "value": [
          1740983983.094,
          "86.86328125"
        ]
      }
    ]
  }
}
```

Это вызвано неверным использованием операции `avg`. Необходимо исправить запрос, убрав
агрегацию `by (pod)`. Исправленное выражение корректно возвращает среднее значение
занятой памяти:

```
> curl -s "http://$PROMETHEUS_URL:9090/api/v1/query" --data-urlencode query='avg(avg_over_time(container_memory_working_set_bytes{pod=~"module-resourse-test-mlcmp-deployment-.*",container!=""}[300s:])) / 1024 / 1024' | jq .
{
  "status": "success",
  "data": {
    "resultType": "vector",
    "result": [
      {
        "metric": {},
        "value": [
          1740983967.764,
          "720.748828125"
        ]
      }
    ]
  }
}
