# Отчет по тестированию модуля автомасштабирования

## Тестирование

1. Проверка наличия сервисного аккаунта с ограниченными правами для балансировщика

Сервисный аккаунт создан и используется балансировщиком:

```
> kubectl get sa -n unip-system-autoscaler
NAME              SECRETS   AGE
default           0         29d
unip-autoscaler   0         29d
```

Права балансировщика ограничены настройкой AUTOSCALER_NAMESPACE_REGEX.

При попытке гибернации сервиса, не подходящего под это условие, корректно выдается ошибка:

```log
2025-03-03 10:21:34,699 INFO: Namespace does not match regex, skipping hibernation
```

2. Наличие доступа и сервисных реквизитов подключения балансировщика к Prometheus

Доступ к Prometheus API есть:

```
> curl -s "http://$PROMETHEUS_URL/api/v1/query" --data-urlencode query='' | jq .
{
  "status": "error",
  "errorType": "bad_data",
  "error": "invalid parameter \"query\": unknown position: parse error: no expression found in input"
}
```

В текущей конфигурации сервер метрик не требует сервисных реквизитов при обращении
изнутри кластера.

3. Тестирование скейлинга вверх/вниз
